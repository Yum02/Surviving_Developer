# 개발자로 살아남기 (Surviving as a Developer)

대한민국 어딘가에서 무작위로 태어나 개발자의 일생을 살아 보는 텍스트 인생 시뮬레이션입니다.
웹 게임 「80억 분의 1」과 비슷한 구조로, 인생이 한 해씩 글로 흘러가고 갈림길에서만 선택합니다.
선택은 확률을 바꿀 뿐 결과를 약속하지 않습니다. 예순까지 개발자로 남으면 생존이고, 그 뒤 노년도 끝까지 이어집니다.

> 등장하는 회사 이름(네이바, 카카우, 삼숭전자, 구골, 메가 등)과 모든 확률은 게임을 위해 지어낸 것이며 실제 통계가 아닙니다.

## 실행 방법

**바로 플레이: https://yum02.github.io/Surviving_Developer/**

`index.html` 한 파일로 동작합니다. 내려받아 브라우저에서 열면 바로 플레이할 수 있고, 설치나 서버가 필요 없습니다.
휴대폰(폭 320px 이상)과 컴퓨터 화면 모두에 맞춰져 있습니다. 컴퓨터에서는 상태, 기록, 계획이 3단으로 나란히 보입니다. 한 번의 인생은 10~15분쯤 걸립니다.

## 현재 버전에 들어 있는 것 (v11)

### 출생
- 이름, 성별, 출생 연도(1996~2006), 출생지, 가정 형편 5단계가 무작위로 정해집니다.
- **부모**: 아버지·어머니 직업, 집안 분위기 7종, 집안 체질 3종이 능력치와 재력에 영향을 줍니다. 형편에 따라 결혼 지원금, 부모님 생활비 부담, 상속이 달라집니다.
- **타고난 것**: 재능·성격·건강·운에 걸친 23가지 특성 중 3가지를 좋고 나쁨 구분 없이 받습니다.

### 능력치
- 항상 보이는 것: 실력, 체력, 멘탈, 인맥, 영어, 자산(현금+투자), 연봉
- 나이와 상황에 따라 보이는 것
  - **공부**(7세~취업 전): 수능 점수의 바탕. 화면에 "지금 성적이면 갈 수 있는 대학"과 다음 단계까지 남은 점수가 표시됩니다.
  - **평판**(취업 후~은퇴 전): 승진, 연봉 협상, 헤드헌터 연락, 권고사직 위험에 영향을 줍니다. 이직하면 4분의 1이 깎입니다.
  - **매력**(13세부터): 고백·청혼 성공률과 면접에 영향을 줍니다. 운동, 여행, 취미, 모임으로 오릅니다.
  - **애정**(연인이나 배우자가 있을 때): 바닥나면 헤어집니다.

#### 진학 기준
| 대상 | 기준 |
|---|---|
| 과학고·영재고 | 공부 60점부터 합격 가능성이 생기고, 80점이면 절반 |
| 최상위권 대학 | 수능 88점 이상 |
| 인서울 대학 | 70점 이상 |
| 지방 국립대 | 54점 이상 |
| 지방 사립대 | 38점 이상 |
| 전문대 | 그 미만 |

수능 점수는 공부 점수에 가정 형편 보정(최대 +6)과 당일 운(대체로 ±7점 안팎)이 더해져 정해집니다.

### 인생의 흐름
유년기 → 중·고교(일반고·마이스터고·과학고) → 수능과 재수 → 대학(동아리, 군대, 인턴, 교환학생, 석사, 미국 유학, 창업) → 구직 → 직장 생활 → 개발자 인생의 결말 → 노년기 → 사망

### 회사
- 한국: SI·중소, 중견 IT, 스타트업, 대기업, 네카라쿠배, 외국계 한국지사
- 미국: 스타트업, 빅테크. 직접 지원 후 H-1B 추첨, 한국지사에서 본사 이동, 미국 석사 세 가지 경로가 있습니다.
- 프리랜서, 창업도 가능합니다.

### 해마다 세우는 계획
7세부터 매년 계획을 미리 정하고, 결과는 이듬해에 나옵니다. 바꾸지 않으면 같은 계획이 이어집니다.
- **시간**: 인생 단계(유년기·청소년기·청년기·중년기·장년기·노년기)마다 다른 활동 42가지. 개인 프로젝트는 2~3년에 걸쳐 완성해 출시합니다.
- **생활**(19세부터): 일하는 방식(저녁을 지킨다 / 평소대로 / 성과에 모든 걸 건다)과 씀씀이(아껴 쓴다 / 평소대로 / 즐기며 쓴다)
- **투자**(19세부터): 예금, 지수 ETF, 개별 기술주, 코인, 배당주, 전부 팔기

### 사건과 선택
- 시기별 사건 묶음: 유년 27, 청소년 27, 대학 22, 구직 8, 직장 51, 노년 30, 연인·부부 18개. 한 인생 안에서 같은 사건은 되풀이되지 않고, 나이 조건이 있습니다.
- 직장 갈림길 35개: 새벽 장애 대응, 레거시 코드, 헤드헌터, 이직, 연봉 협상, 주말 출근, 신사업 전담팀, 우리사주, 창업 제안 등
- **연애와 결혼**: 후보 세 명 중 상대 선택 → 고백 → 연애 중 선택 → 청혼 → 결혼 → 아이. 결혼 전과 후의 사건이 나뉘어 있습니다.

### 결말
- 개발자 인생의 결말 15종: 백발의 현역 개발자, CTO, 실리콘밸리 은퇴, 창업 매각, 조기 은퇴, 치킨집 사장님, 개발 강사, 번아웃, 건강 악화, 공무원 전향 등
- 결과 화면에 이력, 타고난 것, 가족, 발자취(칭호 16종), 같은 해 태어난 네 사람의 결말이 함께 나옵니다.

### 화면
- 도트 캐릭터가 나이, 직업, 컨디션에 따라 바뀝니다.
- 일시정지, 속도 1·2·4배, 자동 선택, 기록을 눌러 다음 줄로 넘기기
- 밝은 화면과 어두운 화면을 모두 지원합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 완성된 게임. 이 파일만 있으면 실행됩니다 |
| `src/engine.js` | 게임 규칙과 모든 사건 글. 화면과 분리되어 있습니다 |
| `src/template.html` | 화면(HTML, CSS, 화면용 스크립트, 도트 캐릭터) |
| `src/rarity.json` | 결말별 빈도. 결과 화면에 표시됩니다 |
| `tools/build.js` | `src`를 합쳐 `index.html`을 만듭니다 |
| `tools/sim.js` | 선택을 무작위로 고르며 인생을 수만 번 돌려 오류와 결말 분포를 확인합니다 |
| `tools/balance.js` | 플레이 방식별 생존율, 결말 비율, 자산을 측정합니다 |
| `CHANGELOG.md` | 버전별 변경 내역 |

## 고친 뒤 다시 만들기

Node.js만 있으면 됩니다.

```bash
node tools/sim.js 20000            # 오류 검사 + 결말 분포 출력
node tools/sim.js 20000 | head -1 > src/rarity.json   # 결말 빈도 갱신
node tools/build.js                # index.html 생성
```

## 현재 밸런스

`node tools/balance.js`로 플레이 방식별 6천 회씩 측정한 값입니다.

| 플레이 방식 | 예순까지 생존 | 건강 악화 | 번아웃 | 사망 시 자산 중앙값 |
|---|---|---|---|---|
| 선택과 계획을 무작위로 | 약 65% | 약 4% | 약 4% | 13억 원 |
| 체력·멘탈이 낮으면 챙기는 신중한 플레이 | 약 74% | 0% | 약 3% | 9억 원 |
| 늘 "성과에 모든 걸 건다" | 약 20% | 약 35% | 약 28% | 10억 원 |

한 인생 평균 기록 약 430줄, 선택 약 48회, 평균 수명 약 83세.

## 알려진 문제와 다음에 손볼 것

- 확률은 실제 통계가 아닙니다. 실제 통계를 반영할지는 정하지 않았습니다.
- 무작위로 플레이해도 예순까지 살아남는 비율이 높은 편입니다. 난이도를 더 올릴지는 플레이 의견을 보고 정합니다.
