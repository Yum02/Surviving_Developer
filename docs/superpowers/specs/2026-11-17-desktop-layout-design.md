# 넓은 화면 배치 설계 (2026-11-17)

## 왜
컴퓨터에서 열면 게임이 화면 가운데 폰 너비(560px)에만 몰려 있어 불편하다는 의견. 완성도를 올리는 첫 작업으로 정했다.

## 목표와 하지 않을 것
- 목표: 컴퓨터의 넓은 화면을 다 쓰고, 상태·진행 기록·계획이 서로 가리지 않게 한다.
- 하지 않을 것: 폰 화면은 바꾸지 않는다. 게임 규칙과 글도 바꾸지 않는다.

## 검토한 방법
| 방법 | 내용 | 장단점 |
|---|---|---|
| A. 2단 | 왼쪽에 상태·조작, 오른쪽에 기록. 계획은 아래에서 열리는 창 | 단순하고 어중간한 폭에도 맞는다. 계획을 바꿀 때마다 창을 열어야 한다 |
| B. 3단 (선택) | 왼쪽 상태·조작, 가운데 기록, 오른쪽에 계획 칸이 항상 열림 | 한눈에 다 보이고 계획을 즉시 바꾼다. 작업이 많고 좁은 화면에서는 쓸 수 없다 |
| 한 줄을 넓히기 | 지금 배치 그대로 폭만 확대 | 글 한 줄이 너무 길어 읽기 불편해 제외 |

사용자가 "가장 좋아 보이는 것"으로 맡겼고, B를 골랐다. 좁은 노트북에서는 A로 자동 전환한다.

## 결정
- 화면 폭 1100px 이상: 3단. 계획 칸은 항상 열려 있고 고르는 즉시 반영된다. 탭 없이 시간·생활·투자를 모두 펼쳐 보여 준다. 인생 단계가 바뀔 때만 멈추고 확인 버튼이 나타난다.
- 760~1099px: 2단. 계획은 기록 칸 아래에서 열린다.
- 760px 미만: 기존 폰 배치 그대로.
- 시작 화면과 출생신고서도 넓은 화면에서 2단으로 배치한다.
- 결과가 나오면 계획 칸과 조작 버튼을 숨기고 기록 칸을 넓힌다.

## 확인한 것
1440px, 960px, 390px 폭에서 한 판씩 끝까지 돌려 오류와 가로 넘침이 없는지 확인했다.
